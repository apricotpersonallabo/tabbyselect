# TabbySelect

長いドロップダウンを、迷わず選ぶ。

TabbySelectは、WebフォームのネイティブHTML select要素をキーボードで素早く検索・選択するためのブラウザ拡張機能です。

## 主な機能

- select要素にフォーカスして文字を入力すると候補を絞り込めます。
- 検索方法は先頭一致と部分一致を選択できます。初期値は部分一致です。
- 矢印キーで候補を移動し、EnterまたはTabで確定できます。
- URLフィルターをオンにすると、対象URLをパターンで制限できます。初期設定はオフで、すべてのHTTP/HTTPSページが対象です。

## 使い始めるまで

1. 対象を制限する場合は「URLフィルターを有効にする」をオンにし、1行1パターンで入力します。すべてのHTTP/HTTPSページで使う場合はオフのままにします。
2. 対象ページでツールバーアイコンから拡張機能を有効にします。
3. Tabキーなどでselect要素へ移動し、検索文字を入力します。
4. 候補を選択してフォーム入力を続けます。

## 対応ブラウザ

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
