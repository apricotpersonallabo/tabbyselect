SMALL TOOL, QUICK FLOW

Less friction in every form

Prefix or contains search

Focus a select and type to filter matching options. Choose prefix or contains matching in settings.

Stay on the keyboard

Move with arrow keys and confirm with Enter or Tab to keep the form moving.

Control by URL

Limit the extension with URL patterns, or leave the setting empty to enable it on every http/https page.

THREE STEPS

Get started

  1. Set target URLs

    Enter one URL pattern per line. Leave the setting empty if you want to use it everywhere.

  2. Turn it on

    Open the toolbar icon on a target page and enable the extension.

  3. Start typing

    Use Tab to focus a select, then type your query. Contains matching is the default; prefix matching is also available.
