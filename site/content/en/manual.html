How to use

Follow the setup and controls, then try the extension on real select elements in the playground below.

Contents 1. Setup 2. Keyboard controls 3. Playground 4. Scope and limits

Setup

  1. Open settings

    Click the TabbySelect toolbar icon and choose “Open settings.”

  2. Set enabled URLs

    Enter one URL pattern per line. * matches any text. An empty setting enables every http/https URL.

    https://example.com/*
  3. Choose a search mode

    In settings, choose Prefix match or Contains match (default). Ja matches Japan in prefix mode; pan matches Japan in contains mode. Both modes ignore case. Changes are saved automatically and apply to open pages and their iframes.

  4. Suggestion display

    Show suggestions on mouse click is on by default. Turn it off to use the native select picker on mouse clicks. Keyboard, touch, and programmatic focus still open suggestions.

  5. Enable it on the page

    Open the icon again and turn on the popup toggle. Setting changes also apply to pages already open.

Keyboard controls

Tab into a select to open its search field immediately. Type to filter, use arrows to navigate and Enter or Tab to confirm. After Escape closes the UI, another qualifying key can reopen it. IME and full-width text are supported.

TextFilter options using the selected search mode
↑ ↓Move the highlighted suggestion
BackspaceRemove one character from the query
EscClear the query; press again while empty to close suggestions
EnterDuring IME conversion, confirm the text. Press again after conversion to confirm the option and move to the next field
TabConfirm and continue with normal Tab navigation

Scope and limits

  • The extension supports native, single-choice HTML select elements. Custom dropdowns and select[multiple] are not supported.
  • Selects in the top page and iframe light DOM are supported, including cross-origin, nested, dynamically added, about:blank, and srcdoc frames. Activation uses the top page URL. Page-owned Shadow DOM is not supported.
  • Only http:// and https:// pages can be enabled. Browser settings pages are not supported.
  • To keep the native select picker on mouse clicks, disable mouse-triggered suggestions in settings. With it enabled, click a suggestion to select it.
