Suggestion display

Off by default. On supported browsers, enabling this changes the appearance of selects and their lists. A key press while the list is open closes it and opens the search field. The first character is preserved; the value changes only when confirmed. Arrow keys, Escape, Tab, modifier keys alone, and shortcuts keep their normal behavior. Changes apply to open pages and iframes. Turning this off restores the original appearance.

This browser does not support this setting. The original select list is used.
